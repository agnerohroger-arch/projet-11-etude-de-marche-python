# Projet 11 — Étude de marché avec Python

## Présentation du projet

Ce projet a été réalisé dans le cadre de ma formation Data Analyst chez OpenClassrooms.

L'objectif est de réaliser une étude de marché internationale afin d'identifier les pays présentant les meilleures opportunités de développement commercial.

L'analyse repose sur l'exploitation, le nettoyage et la comparaison de données relatives à plusieurs pays.

## Problématique métier

**Comment identifier et comparer les pays les plus attractifs pour orienter une stratégie de développement à l'international ?**

## Outils et technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Analyse exploratoire des données
- Visualisation des données

## Méthodologie

1. Compréhension du besoin métier et définition des objectifs de l'étude.
2. Importation et exploration des données internationales.
3. Vérification de la qualité des données et traitement des valeurs manquantes.
4. Préparation des indicateurs nécessaires à la comparaison des pays.
5. Analyse statistique et visualisation des données.
6. Comparaison des pays selon les critères étudiés.
7. Interprétation des résultats pour orienter les décisions stratégiques.

## Analyses réalisées

L'étude s'articule autour de plusieurs axes :

- Exploration des caractéristiques des pays étudiés.
- Analyse et comparaison des indicateurs disponibles.
- Identification des différences entre les marchés.
- Production de graphiques facilitant l'interprétation.
- Évaluation des opportunités de développement international.

## Résultats et recommandations

L'objectif des analyses est de dégager une sélection de pays cibles à partir d'indicateurs comparables et de critères métier.

Les résultats chiffrés, le classement final et les recommandations spécifiques seront ajoutés après vérification du notebook d'analyse.

## Compétences démontrées

- Nettoyage et préparation des données avec Python.
- Analyse exploratoire et statistique.
- Manipulation de données avec Pandas.
- Création de visualisations.
- Comparaison d'indicateurs internationaux.
- Interprétation des résultats.
- Aide à la décision stratégique.
- Communication des analyses.

## Livrables

Le projet comprend un notebook Python présentant les traitements, les analyses et les visualisations réalisés.

Le notebook sera ajouté à ce dépôt après vérification des fichiers et des données pouvant être publiés.
